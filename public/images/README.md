# Image slots

The app intentionally ships without original board-game artwork. Add later images at these paths; WebP is recommended.

- `corpse.webp`: central scene, landscape crop
- `cards/student-president.webp`
- `cards/health-committee.webp`
- `cards/library-committee.webp`
- `cards/discipline-committee.webp`
- `cards/young-lady.webp`
- `cards/news-club.webp`
- `cards/class-representative.webp`
- `cards/honor-student.webp`
- `cards/criminal.webp`
- `cards/accomplice.webp`
- `cards/alien.webp`
- `cards/infected.webp`
- `cards/go-home-club.webp`

Missing files automatically render as labeled placeholders. Card images use a 3:2 crop inside a fixed card layout.
